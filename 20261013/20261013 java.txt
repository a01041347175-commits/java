java
class : 프로그램 구성 단위, java 응용프로그램에서 하나 이상은 반드시 있어야 한다.
		java 응용프로그램 안에 여러 클래스, 그 안에 기능이 있거나 한다.
		
클래스의 기본형식 : public과 class 키워드를 클래스 이름앞에 붙이고 중괄호{}를 사용해서 코드작성
ex) public class Hello{}

키워드 : 특정 목적으로 정의된 예약어, java에서 정의해 놓은 목적이외에 사용할수 없다.
public과 class는 클래스를 선언할때 사용하는 키워드로 클래스 이름으로 사용할수 없다.

클래스 이름 : java파일명과 동일해야 한다. 하나의 파일에는 하나의 클래스가 일반적.
			만약, 하나의 파일에 클래스가 두개 이상이라면 class앞에 public이 붙지 않는다.

클래스 이름 : 영문 대문자로 시작하는것이 일반적, 숫자가 필요하다면 중간이나 마지막에 사용.
클래스 이름 : 클래스 이름에 특수문자를 사용시에는 _ $ 만 사용 가능.


main 메서드 : java 응용프로그램을 실행하면 JVM은 프로그램 내 많은 코드 중에서 가장먼저 시작해야하는 코드를
			 찾아야 하는데, 이때 가장 먼저 실행하는 코드가 main 메서드. 
			 JVM은 main 메서드를 프로그램의 시작점으로 생각.
			 ex)public static void main(String[] args) {}

main 메서드는 프로그램에서 하나만 존재해야한다. 만약 main 메서드가 두개이상이면 선택창이 나온다.


코드블록 : 클래스와 메서드는 각각 코드의 시작과 끝을 가지고 있다. 
		  이때 코드의 시작부터 끝까지를 코드블럭 이라고 한다.
		  ex) public class Hello{
					public static void main {
						sysdlfkj
					} - main 메서드 코드블럭
			  } - 클래스 코드블럭
			  
들여쓰기 : 코드블록 안에서는 구분(가독성)을 위해서 들여쓰기를 하지만 {}로 시작과 끝을 정하기 때문에 들여쓰기로 인해서 오류가 나지는 않는다.


세미콜론 : 프로그램의 문장에 끝에 ; 작성

주석 : // 한줄 주석 /* */ 여러줄 주석  (javascript와 동일
